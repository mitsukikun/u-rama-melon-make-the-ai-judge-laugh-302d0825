## Description

One line of office life, written for the "Make the AI Judge Laugh" competition: an analyst builds a pivot table so beautiful that the manager promotes the spreadsheet itself and forgets the person who made it. The joke lands on a true office observation — credit flowing upward to the artifact instead of the worker — and turns on an unexpected last word, staying tight at 90 characters so it reads cleanly aloud in a single breath.

## Run it

```bash
python3 main.py
```
